# Back-end

Για testing τρέχουμε:
`npm run test`


Για να εγκατασταθούν τα modules τρέχουμε:
`./build_deploy.sh`

Για να υπολογιστούν και να προστεθούν οι οφειλές στην βάση εκτελούμε:
`npm run settlements`

(Δεν χρειάζεται γιατί οι οφειλές είναι ήδη αποθηκευμένες στο dump της βάσης)

Περιεχόμενα:

- Πηγαίος κώδικας εφαρμογής για εισαγωγή, διαχείριση και
  πρόσβαση σε δεδομένα (backend).
